**Меняй размер хитбокса и положение камеры прямо в игре**

## ✨ Возможности

| | Функция | Описание |
|---|---|---|
| 📐 | **Размер хитбокса** | Ползунки ширины и высоты хитбокса игрока |
| 👁️ | **Высота глаз** | Положение глаз внутри хитбокса |
| 🎥 | **Положение камеры** | Сдвиг камеры влево / вправо, вниз / вверх, назад / вперёд |
| 🧍 | **Вид от первого лица** | Ты видишь мир из выбранного положения камеры |
| 🔄 | **Кнопка «Сброс»** | Одним нажатием возвращает всё к стандартным значениям |
| 💾 | **Автосохранение** | Настройки запоминаются между запусками игры |
| 🖼️ | **Живой предпросмотр** | Справа показаны фигурка игрока, зелёная рамка хитбокса и жёлтый квадрат камеры |

---

## 🕹️ Как пользоваться

1. Зайди в мир.
2. Нажми **`H`** — откроется меню настроек.
3. Двигай ползунки. Результат сразу виден в панели предпросмотра и в игре.
4. **Сброс** — вернуть всё как было. **Готово** — закрыть меню и сохранить.

> 💡 Клавишу можно поменять: **Настройки → Управление → «Открыть настройки хитбокса и камеры»**.

### Диапазоны значений

| Параметр | Минимум | Стандарт | Максимум |
|---|:---:|:---:|:---:|
| Ширина хитбокса | 0.1 | 0.6 | 4.0 |
| Высота хитбокса | 0.2 | 1.8 | 6.0 |
| Высота глаз | 0.1 | 1.62 | 6.0 |
| Камера (каждая ось) | −5.0 | 0.0 | +5.0 |

Все значения указаны в блоках.

## 📦 Установка

1. Установи **Minecraft 26.3** и **[NeoForge 26.3](https://neoforged.net/)**.
2. Скачай `hitboxcam-*.jar` из раздела **[Releases](../../releases/latest)**.
3. Положи файл в папку `mods`:
   - Windows: `%appdata%\.minecraft\mods`
   - Linux: `~/.minecraft/mods`
   - macOS: `~/Library/Application Support/minecraft/mods`
4. Запусти игру через профиль **NeoForge**.

---

## ⚠️ Важно знать

- Мод **клиентский**: ставится только на твой компьютер, на сервер ставить не нужно.
- Хитбокс меняется **только на твоей стороне**. Сервер о нём не знает и считает столкновения и урон по обычному размеру.
- Размер меняется для стоячей позы; приседание и плавание остаются ванильными.
- Мод находится на ранней стадии, а Minecraft 26.3 и NeoForge для неё ещё в бета-версии, поэтому возможны ошибки.

## 🛠 Сборка из исходников

Нужны **JDK 25** и **Gradle 9.1+**.

```bash
git clone https://github.com/felovdev/hitboxcam.git
cd hitboxcam
gradle build
```

Готовый файл появится в `build/libs/`.

Сборка также автоматически запускается на GitHub (**Actions**), а при публикации тега `v*` jar прикрепляется к релизу.

---

## 📁 Конфигурация

Настройки хранятся в файле `config/hitboxcam.properties`. Чтобы вернуть всё к стандарту, нажми «Сброс» в меню или удали этот файл.
