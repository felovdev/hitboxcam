# Hitbox & Camera Tweaker (NeoForge 26.3)

Сборка (нужны JDK 25 и интернет):

    gradle wrapper --gradle-version 9.1.0     # один раз, если нет gradlew
    ./gradlew build                           # Windows: gradlew.bat build

Готовый мод: build/libs/hitboxcam-1.0.0.jar -> положить в папку mods.
В игре: клавиша H открывает меню (меняется в настройках управления).
Настройки сохраняются в config/hitboxcam.properties.
